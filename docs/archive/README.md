# Archive

This folder holds historical and superseded documentation and records —
plans, notes, or write-ups that described a decision, a state, or an intent
that no longer holds.

**Everything under this folder is historical context only.** It captures what
was true or planned at some point in the past. It must not be used to
understand the current state of this project, and it must not guide new work
— code, decisions, or documentation. Contributors and coding agents should
treat anything here the way they'd treat an old email thread: useful for
understanding *how we got here*, never a substitute for reading the current
docs, code, or ADRs.

If something in here still matters going forward, that's a sign it belongs
back in live documentation, not in this folder.
